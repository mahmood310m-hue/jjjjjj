# تطبيق مدرسة الكوثر الأهلية المختلطة

## طريقة الحصول على ملف APK
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد (بما فيه مجلد `.github`).
2. افتح تبويب **Actions** وانتظر انتهاء البناء (حوالي ٥ دقائق). يمكن تشغيله يدويًا بزر **Run workflow**.
3. افتح آخر عملية بناء ثم نزّل **kawthar-school-apk** من قسم Artifacts، وفيه الملف `app-debug.apk`.
4. انقل الملف إلى الهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

## تعديل المحتوى
كل الأسماء والأخبار والمراحل والدرجات في ملف واحد: `www/data.js`.
الشعار: `www/logo.svg`. الألوان: متغيرات `:root` أعلى ملف `www/index.html`.

## ملاحظة
الأسماء والدرجات الحالية تجريبية. قبل نشر أسماء أو درجات حقيقية لطلبة، احصل على موافقة أولياء الأمور.
